# SDP Employee UI (React + Vite)

## Run (VS Code / Terminal)
```bash
npm install
npm run dev
```

## Notes
- Dummy data only (no backend).
- Employee pages implemented: Dashboard, Manage Inventory (All + Add Product modal), Sales & Billing, Reservations, Reports (Sales), Customers, Low Stock, Alerts (All), Settings (System Preferences).


## Admin Routes
- /admin/dashboard
- /admin/inventory
- /admin/pending
- /admin/sales-history
- /admin/reservations
- /admin/reports/sales
- /admin/low-stock
- /admin/user-management
